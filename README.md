# AI CV Skill Gap

Dự án nghiên cứu và xây dựng hệ thống phân tích khoảng cách kỹ năng trên CV bằng AI.

## Cấu trúc thư mục

- `docs/requirements/` — tài liệu yêu cầu, mục tiêu, phạm vi dự án
- `docs/architecture/` — sơ đồ kiến trúc, thiết kế hệ thống
- `data/raw/` — dữ liệu thô, CV mẫu, dataset gốc
- `data/processed/` — dữ liệu đã tiền xử lý, vector hóa, chuẩn hóa
- `notebooks/` — phân tích dữ liệu, thử nghiệm mô hình
- `src/ai/` — mô hình AI, tiền xử lý, đánh giá
- `src/api/` — API backend
- `src/web/` — frontend hoặc giao diện người dùng
- `tests/` — test, kiểm thử, validation

## Giai đoạn đề xuất

1. Nghiên cứu yêu cầu và phạm vi dự án
2. Thu thập và tiền xử lý dữ liệu CV
3. Xây dựng mô hình đánh giá kỹ năng dựa trên AI
4. Tạo API và giao diện người dùng
5. Kiểm thử và đánh giá hiệu suất
