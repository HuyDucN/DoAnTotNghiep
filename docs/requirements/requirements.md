# Yêu cầu dự án

## Mục tiêu
- Phân tích CV và so sánh với yêu cầu công việc
- Xác định khoảng cách kỹ năng (skill gap)
- Gợi ý cải thiện kỹ năng cho ứng viên

## Tính năng chính
- Upload CV
- Trích xuất kỹ năng từ CV
- So sánh với job description
- Đánh giá mức độ phù hợp
- Gợi ý đề xuất học tập hoặc nâng cao kỹ năng

## Giới hạn
- Dữ liệu đầu vào phụ thuộc vào chất lượng CV
- Mô hình cần được đánh giá trên tập dữ liệu representative
- Hệ thống cần có giao diện dễ sử dụng
